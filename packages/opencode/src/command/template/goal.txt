## How Goal Mode Works

1. Immediately use `update_goal` with `objective` set to the goal description above. Do NOT set a token_budget unless explicitly asked by the user.
2. Use `update_goal` with `status="complete"` when the goal is fully achieved
3. Use `goal_status` to check your current progress

### On Stopping

Goal mode stops when:
- The goal is fully achieved (mark it `status="complete"`)
- You receive a new user message (explicit interruption)
- An unrecoverable error blocks all possible approaches
